## 📖 專案簡介 (Introduction)

在日常使用 **Gemini、ChatGPT、Claude** 等 AI 工具整理筆記、撰寫技術報告或繪製系統架構圖時，常會遇到複製出來的 Markdown 格式跑版（如表格斷裂、雙重超連結、清單縮排遺失、數學符號變成原始碼）或缺乏即時圖表預覽與高品質匯出工具的困擾。

**Markdown & Mermaid Web Viewer** 專為解決上述痛點而生：
* **⚡ 開箱即用、零操作阻力**：開啟網頁即自動聚焦編輯區，無須註冊帳號、無須先用滑鼠點選，直接按下 `Ctrl + V`（或 `Cmd + V`）即可貼上文字並即時預覽排版結果。
* **✨ 專治 AI 複製跑版**：內建針對 AI 回覆特別最佳化的「**自動修正**」引擎，一鍵還原破損表格、錯位粗體超連結與遺失的巢狀清單縮排。
* **📊 完整視覺化圖表與公式渲染**：原生支援 **33 種 Mermaid 向量圖表**、**LaTeX 出版級數學公式**、**GitHub 風格提示框 (Alerts)** 與**程式碼語法高亮**。
* **📤 專為閱讀與分享打造的匯出體驗**：除了標準 `.md`、單一離線 `.html` 與防截斷 `.pdf` 外，更提供適配手機與平板閱讀比例的 **3x Retina 超高解析度 `.png` 長圖匯出**，方便直接傳送至 LINE、Slack、Discord 或社群平台分享。
* **🛡️ 絕對隱私與無痕暫態**：所有內容 100% 於您的瀏覽器記憶體中即時運算，**絕不上傳任何伺服器，亦不在電腦本機留下任何快取紀錄**，關閉分頁即徹底抹除。

## 🚀 快速上手與操作說明 (Quick Start Guide)

### 步驟 1：輸入或載入 Markdown 內容
您可以透過以下任一方式開始使用：
1. **直接貼上或打字**：打開網頁後直接按鍵盤打字，或在任何模式下按 `Ctrl / Cmd + V` 直接貼上剪貼簿中的文字。
2. **拖曳檔案載入**：將電腦中的 `.md`、`.markdown` 或 `.txt` 檔案直接拖曳至瀏覽器視窗中放開，即可自動載入內容與檔名。
3. **開啟本機檔案**：點擊頂部工具列的「**開啟**」按鈕，從電腦選擇檔案匯入。
4. **體驗範例模板**：點擊頂部工具列的「**範例**」按鈕，立即載入包含流程圖、時序圖、表格、程式碼與數學公式的完整展示文件。
5. **自訂文件名稱**：點擊左上角標題列旁的檔名輸入框（預設為 `Untitled.md`），即可隨時修改匯出時的預設檔案名稱。

### 步驟 2：一鍵修復 AI 排版瑕疵 (`Alt + F`)
若您的內容是從 Gemini 或 ChatGPT 等 AI 對話介面複製而來：
* 點擊頂部工具列的「**✨ 修正**」按鈕（或按下快速鍵 `Alt + F`）。
* 系統將自動修補斷裂的表格、收斂雙重超連結、補齊子清單縮排並將 LaTeX 比較符號轉為易讀符號，同時於畫面右下角提示本次完成了哪些修復項目（若對結果不滿意，可隨時按 `Ctrl / Cmd + Z` 復原）。

### 步驟 3：切換檢視版面與閱讀模式 (`Alt + 1 / 2 / 3 / M / Z`)
透過畫面右上角的**三態切換器**，依您的工作情境自由切換：
* **純編輯 (`Alt + 1`)**：隱藏預覽區，提供 100% 寬度的無干擾專注寫作空間。
* **雙欄對照 (`Alt + 2`)**：左側編輯原始碼、右側即時同步預覽，並可拖曳中央分隔線調整左右欄寬比例（15% ~ 85%）。
* **純瀏覽 (`Alt + 3`)**：隱藏編輯器與次要工具，將畫面轉為極簡置中的技術文件閱讀版面：
  * **切換閱讀寬度 (`Alt + M`)**：在純瀏覽模式下，可由右上角選單切換「**自適應寬度**」、「**平板直式 (834px)**」或「**手機直式 (412px)**」，預覽不同裝置的真實排版效果。
  * **專注全螢幕閱讀 (`Alt + Z`)**：一鍵隱藏頂部工具列進行沉浸式閱讀；將滑鼠移至畫面或點擊懸浮膠囊即可隨時顯示工具列或返回雙欄對照（亦可直接按 `Escape` 返回）。

### 步驟 4：匯出與分享文件
點擊右上角紫色的「**匯出**」按鈕，選擇您需要的輸出格式：
* **匯出 Markdown (`.md`)**：下載標準 UTF-8 純文字檔案。
* **匯出 HTML (`.html`)**：下載包含完整配色、樣式與向量圖表的單一網頁檔，無須網路即可在任何裝置打開瀏覽。
* **列印 / 匯出 PDF (`.pdf`)**：開啟系統列印對話框，自動套用高對比白底黑字與防跨頁截斷保護，儲存為專業 PDF 文件。
* **匯出圖片 (3x 超高解析度 `.png`)**：選擇「**手機直式 (412px)**」、「**平板直式 (834px)**」或「**自適應寬度**」，一鍵產出 3 倍 Retina 超高解析度長圖。

### 1. ✨ AI / Gemini 排版智慧「自動修正」引擎 (`Alt + F`)

| 常見 AI 複製排版問題 | 修正前範例 | 自動修正後結果 |

### 2. 📊 Mermaid 向量圖表、數學公式與進階 Markdown 語法
* **Mermaid 向量圖表即時渲染**：
  * 支援流程圖 (`flowchart` / `graph`)、時序圖 (`sequenceDiagram`)、類別圖 (`classDiagram`)、狀態圖 (`stateDiagram-v2`)、實體關聯圖 (`erDiagram`)、甘特圖 (`gantt`)、圓餅圖 (`pie`)、C4 架構圖、心智圖 (`mindmap`)、時間軸 (`timeline`)、GitGraph 等 **33 種圖表類型**。
  * 圖表色彩會隨全站「淺色／深色主題」**零延遲即時變換**，確保在深色曜黑與淺色紙白背景下皆清晰易讀。
  * 當您正在打字、圖表語法尚未輸入完成時，預覽區會貼心顯示錯誤所在的**精確行號與欄位提示**（例如 `[行 2, 欄 5]`），不會導致畫面崩潰或中斷其他段落的預覽。
* **KaTeX 出版級數學公式**：
  * 支援行內公式（如 `$E = mc^2$`）與多行獨立展示區塊公式（以 `$$` 包裹）。
  * 內建智慧防誤判機制，日常文字中的金額表示（如 `$20 and $30`）不會被誤當成數學公式渲染。
* **GitHub 風格提示區塊 (GFM Alerts)**：
  * 支援 `> [!NOTE]`（資訊）、`> [!TIP]`（技巧）、`> [!IMPORTANT]`（重要）、`> [!WARNING]`（警告）、`> [!CAUTION]`（危險）五種醒目視覺提示框，且提示框內部可自由包含多段落、清單、表格與程式碼。
* **程式碼語法著色與 GFM 待辦核取清單**：
  * 支援主流程式語言自動語法高亮，並將 `- [ ]` 與 `- [x]` 自動渲染為美觀的核取方塊。

### 3. 📐 雙向捲動同步與自訂裝置閱讀視圖
* **等比雙向捲動同步**：
  * 在「雙欄對照」模式下，捲動左側編輯器或右側預覽區時，另一側會依文章比例平滑同步捲動，方便長文對照校稿。
  * 若想暫時獨立捲動單側畫面，可隨時點擊底部狀態列右側的「**捲動同步：開 / 關**」按鈕切換。
* **所見即所得的裝置閱讀模式 (`Alt + M`)**：
  * 切換至「**純瀏覽 (`Alt + 3`)**」模式時，工具列會出現閱讀視圖選單（亦可按 `Alt + M` 快速循環切換）：
    1. **自適應寬度**：依目前螢幕視窗彈性置中排版（預設）。
    2. **平板直式 (834px)**：模擬 11 吋 iPad (4:3) 閱讀比例，兼具圖表展開空間與最佳文字行寬。
    3. **手機直式 (412px)**：模擬 6.3 吋手機 (18:9) 螢幕寬度，可提前預覽手機長圖的自動換行與圖表縮放效果。

### 4. 📤 四合一多格式匯出與 3x Retina 長圖
* **Markdown (`.md`)**：匯出乾淨的 UTF-8 `.md` 原始碼檔案。
* **獨立自給 HTML (`.html`)**：將整篇排好版的文章、主題配色、程式碼高亮與所有 SVG 向量圖表封裝進單一 `.html` 檔案中。收到檔案的人無須安裝任何軟體、甚至在沒有網路的環境下，直接用瀏覽器點開就能看到一模一樣的精美排版。
* **列印級無損 PDF (`.pdf`)**：自動將深色背景反轉為最適合閱讀與紙本列印的白底黑字高對比樣式，並自動保護表格、程式碼區塊與 Mermaid 圖表不被跨頁攔腰截斷。
* **3x 超高解析度 PNG 長圖 (`.png`)**：
  * 提供 **手機直式 (412px)**、**平板直式 (834px)** 與 **自適應寬度** 三種版面規格。
  * 採用 **3 倍 Retina 像素密度**渲染，無論在手機螢幕放大檢視細節或查看複雜流程圖，文字與線條皆銳利不模糊。
  * 自動跟隨您當前選擇的主題背景（☀️ 淺色紙白 或 🌙 深色曜黑），並自動以 `<文件名稱>-YYYYMMDD-HHmmss.png` 時間戳記命名。

### 7. 🛡️ 無痕暫態隱私保護與防誤關機制 (Zero-Persistence)
* **零本機殘留、零雲端上傳**：本工具不設任何後端資料庫，亦不使用瀏覽器的 `localStorage`、`IndexedDB` 或 `Cookie` 儲存您的文章。您貼上的任何機密程式碼、會議紀錄或私人筆記僅存在當下分頁的記憶體中。
* **防誤觸關閉保護**：當您在編輯器中輸入或修改內容後，若尚未匯出就不小心按到重新整理（`F5`）或關閉分頁，瀏覽器會自動跳出確認提示，避免未儲存的心血意外遺失。

* **底部狀態列右側**：提供「**捲動同步：開 / 關**」切換按鈕、**版本號徽章**（點擊可檢查更新）與檔案編碼標示（`UTF-8`）。

## ❓ 常見問題 (FAQ)

**Q1：我關閉網頁或重新整理後，剛剛寫的文章找得回來嗎？**
> 找不回來。為了確保最高等級的隱私安全（Zero-Persistence），本工具不會在您的瀏覽器或任何伺服器儲存文件內容。請在關閉分頁前，務必透過右上角「**匯出**」按鈕將內容下載為 `.md`、`.html`、`.pdf` 或 `.png` 保存。

**Q2：為什麼在「純編輯」模式下，匯出選單裡的 PNG 圖片選項無法點擊？**
> 因為 PNG 長圖是根據右側預覽區的實際渲染畫面進行繪製。請先按 `Alt + 2`（雙欄對照）或 `Alt + 3`（純瀏覽）讓預覽區完成渲染，即可正常匯出 3x 超高解析度 PNG 長圖。

**Q3：匯出的 `.html` 檔案傳給別人後，對方沒有網路也能看到 Mermaid 圖表跟數學公式嗎？**
> 可以。本工具匯出的 `.html` 已將所有排版樣式與向量圖表（SVG）完整內嵌於單一檔案中，不依賴外部網路連線即可完整呈現。
